# Lag-Free Ultrabullet

An independent hyperfast chess platform based on the open-source Lila application.

This repository incorporates modified source code from [lichess-org/lila](https://github.com/lichess-org/lila).
See [UPSTREAM.md](UPSTREAM.md), [COPYING.md](COPYING.md), and [LICENSE](LICENSE) for provenance,
copyright, licensing, and third-party asset notices.

The previous React/Supabase prototype is preserved in [legacy-ultrabullet/](legacy-ultrabullet/)
as a reference for custom product features, including the requested hyperfast time controls.
It is not the active application.

This project is independent and is not affiliated with or endorsed by Lichess.
