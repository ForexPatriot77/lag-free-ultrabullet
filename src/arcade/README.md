# Arcade integration attribution

The native Lag-Free Ultrabullet Arcade page is a React implementation adapted from the gameplay concepts and mechanics in [ForexPatriot77/Donttap-v3](https://github.com/ForexPatriot77/Donttap-v3).

Original project credits: Don'ttap v2 by Sentero-esp12, updated by SpiffyCheese, and further cleaned up and extended by ForexPatriot77.

The integration is not an iframe and does not load the separate GitHub Pages site. Its Frenzy, Endurance, and Cheat modes are implemented as a native React page in `src/components/ArcadePage.tsx`, styled to fit the Lag-Free interface.
